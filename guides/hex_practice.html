Master Lowercase Hex Guide (a-z)

Range: 0x61 ('a') → 0x7A ('z')

1 First Half: 'a' to 'o' (High Nibble '6')

Letters a through o all start with hex digit 6.

• 'a' = 0x61 (Offset 0)
• 'j' = 0x6A (10th letter = A)
• 'o' = 0x6F (15th letter = F)
2 Second Half: 'p' to 'z' (High Nibble '7')

Letters p through z roll over and start with hex digit 7.

• 'p' = 0x70 (Reset second digit to 0)
• 't' = 0x74 ('t' is 4 positions past 'p')
• 'z' = 0x7A (26th letter = 7A)
